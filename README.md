# SermonPrint

SermonPrint is an Obsidian plugin for writing, editing, and exporting sermon manuscripts from a dedicated manuscript view.

## Command

- **SermonPrint: Edit & Export**

This opens the SermonPrint manuscript editor. From that view you can choose page size, edit the sermon, save, export PDF, or export booklet.

## Default page size

- Half sheet: **5.5 × 8.5**

## Development

```
npm install
npm run dev     # esbuild watch build
npm run build   # production build
npm run check   # type-check (tsc --noEmit) then production build
```

`main.js` and `ManuscriptHtml.js` are generated by esbuild from `src/` and are committed to
the repository, along with the hand-written `exporter.js` and `booklet.js`. All four are part
of plugin distribution — Obsidian and the export child process load them directly — so run
`npm run build` and commit the results before releasing.
